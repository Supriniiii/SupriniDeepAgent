# Architecture Engineering Checklist

- [ ] Architectural drivers identified and prioritized from requirements
- [ ] Candidate patterns evaluated against drivers using evaluation matrix
- [ ] Pattern selected with documented justification and rejected alternatives
- [ ] Complete architecture specification produced (architecture.md)
- [ ] ADRs written for all significant architectural decisions
- [ ] Architecture diagrams generated at appropriate abstraction levels
- [ ] Interfaces defined between all major component boundaries
- [ ] Failure modes and recovery strategies documented
- [ ] Observability requirements addressed (logging, metrics, tracing)
- [ ] Architecture validated against non-functional requirements
