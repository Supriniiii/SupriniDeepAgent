# Component Engineering Checklist

- [ ] All required components extracted from architecture specification
- [ ] Component registry searched — all reuse opportunities identified
- [ ] Reuse decision documented for each component (reuse, adapt, or build new)
- [ ] No duplicated functionality — existing components reused wherever possible
- [ ] Each new component has a single, clearly defined responsibility
- [ ] Interface contracts defined for all component boundaries (inputs, outputs, errors)
- [ ] Dependency graph produced with no circular dependencies
- [ ] Build order established for implementation sequencing
- [ ] Component plan validated against architecture specification
- [ ] New components designed for independent testing and future reuse
