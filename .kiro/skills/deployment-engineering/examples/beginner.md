# Beginner Example

## Prompt
"Generate a Dockerfile and basic deployment configuration for a simple chatbot agent."

## Expected Behavior
The skill analyzes the simple single-service architecture, generates an optimized multi-stage Dockerfile, creates a docker-compose.yml for local development, and produces basic deployment instructions.

## Expected Output
- Dockerfile with multi-stage build (builder + runtime)
- docker-compose.yml for local development and testing
- Basic deployment-plan.md with manual deployment steps
- Health check endpoint configuration
