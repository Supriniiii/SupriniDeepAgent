# Documentation Engineering

## Purpose
Generates comprehensive documentation packages for Deep Agents covering architecture, APIs, deployment, and developer guides. Ensures every generated system is fully documented, maintainable, and accessible to operators and developers.

## Responsibilities
- Analyze engineering artifacts to determine documentation scope
- Generate project README with quickstart guide
- Generate architecture documentation with diagrams
- Generate API documentation from interfaces and contracts
- Generate deployment and operations guides
- Generate developer guides and contribution instructions
- Validate documentation completeness against standards
- Produce cohesive documentation packages

## Inputs
- Generated agent artifacts (code, config, specs)
- Architecture decision records
- API interfaces and contracts
- Deployment configurations

## Outputs
- README.md
- Architecture documentation
- API documentation
- Developer and deployment guides

## Dependencies
- Documentation Engineering Engine (conceptual)
- Knowledge Base (all domains)
- Documentation Templates
- Style Guides

## Integration
- Generation Orchestration Engine
- Documentation Engineering Engine
- Validation Engineering Engine
- Evaluation Engineering Engine

## Usage
Invoke this skill when a generated agent requires documentation, when existing documentation needs updating after changes, or when documentation completeness needs to be assessed.

## Best Practices
- Generate documentation alongside code, not as an afterthought
- Keep documentation close to the artifacts it describes
- Use consistent formatting and terminology throughout
- Include practical examples and quickstart guides
- Validate documentation accuracy against actual implementation

## Engineering Standards
- Follows DAEP Engineering Standards
- Uses Knowledge Base
- Invokes Engineering Engines
- Consumes Templates
- Produces deterministic outputs
