# Advanced Example

## Prompt
"Generate enterprise-grade documentation for a distributed multi-agent platform including architecture decision records, comprehensive API docs with OpenAPI specs, operations runbooks, SRE playbooks, prompt catalog, and component catalog."

## Expected Behavior
The skill produces a complete enterprise documentation suite including ADRs for all major decisions, auto-generated OpenAPI specifications, detailed operations runbooks for common scenarios, SRE playbooks for incident response, a versioned prompt catalog, and a searchable component catalog with interface documentation.

## Expected Output
- README.md with executive summary, architecture overview, and navigation guide
- Architecture Decision Records (ADR-001 through ADR-N) with context, decision, and consequences
- OpenAPI 3.0 specification with schema definitions and example requests
- Operations runbooks for deployment, scaling, backup, and recovery
- SRE playbooks for incident detection, response, and post-mortem
- Prompt catalog with versioned prompts, inputs, outputs, and evaluation criteria
- Component catalog with responsibilities, interfaces, dependencies, and usage examples
