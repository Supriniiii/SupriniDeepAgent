# Beginner Example

## Prompt
"Generate a README and basic documentation for a simple chatbot agent."

## Expected Behavior
The skill analyzes the simple agent structure, generates a clear README with project purpose, quickstart instructions, configuration options, and basic usage examples. Includes a minimal architecture overview section.

## Expected Output
- README.md with purpose, installation, configuration, quickstart, and usage sections
- Basic architecture overview describing the single-agent structure
- Configuration reference listing all environment variables
- Simple API usage examples
