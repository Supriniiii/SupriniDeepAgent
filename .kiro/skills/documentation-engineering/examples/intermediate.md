# Intermediate Example

## Prompt
"Generate complete documentation for a multi-component data processing agent including architecture docs, API reference, deployment guide, and developer setup instructions."

## Expected Behavior
The skill analyzes the multi-component architecture, generates comprehensive documentation for each component and their interactions, creates an API reference from interface definitions, produces deployment instructions for container-based deployment, and writes a developer guide with local setup steps.

## Expected Output
- README.md with overview, architecture summary, and quickstart
- Architecture documentation with component diagrams and interaction flows
- API reference with endpoint descriptions, request/response examples, and error codes
- Deployment guide with Docker and Kubernetes instructions
- Developer guide with local setup, testing, and contribution guidelines
