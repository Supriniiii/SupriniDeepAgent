# Advanced Example

## Prompt
"Perform a full production-readiness evaluation of a distributed multi-agent system with 5 coordinating agents, event-driven communication, durable state, and external API integrations. Include performance benchmarking under load and security posture assessment."

## Expected Behavior
The skill performs deep evaluation across all quality dimensions for each agent and the system as a whole, evaluates inter-agent communication efficiency, assesses distributed state consistency, benchmarks performance under simulated load conditions, evaluates security posture including authentication flows and data protection, and produces a comprehensive production-readiness assessment with go/no-go recommendation.

## Expected Output
- evaluation-report.md with system-level and per-agent evaluations, production-readiness verdict
- quality-metrics.md with detailed scores across 10+ dimensions for each agent and aggregate
- benchmark-results.md with performance data, latency percentiles, throughput, and error rates
- optimization-recommendations.md with critical/high/medium priority improvements and estimated effort
