# Beginner Example

## Prompt
"Evaluate the quality of a simple FAQ chatbot agent that was just generated."

## Expected Behavior
The skill reviews the agent's validation report, evaluates basic engineering quality (code structure, naming, documentation), assesses the simple architecture, and produces a quality score with basic improvement suggestions.

## Expected Output
- evaluation-report.md with overall score and per-dimension breakdown
- quality-metrics.md showing scores for each evaluation dimension
- benchmark-results.md comparing against baseline for simple agents
- optimization-recommendations.md with prioritized improvement suggestions
