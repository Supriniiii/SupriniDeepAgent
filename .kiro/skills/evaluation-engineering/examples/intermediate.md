# Intermediate Example

## Prompt
"Evaluate a multi-step research agent that uses semantic memory and multiple tool integrations. Compare against the previous version's evaluation results."

## Expected Behavior
The skill performs a comprehensive evaluation across all dimensions, pays special attention to memory strategy effectiveness and tool integration quality, compares current scores against previous evaluation baselines, identifies regression areas, and produces trend analysis alongside optimization recommendations.

## Expected Output
- evaluation-report.md with detailed per-dimension analysis and trend comparison
- quality-metrics.md showing current scores with delta from previous evaluation
- benchmark-results.md with historical comparison and regression identification
- optimization-recommendations.md with prioritized improvements focused on regression areas
