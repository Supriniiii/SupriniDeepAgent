# Advanced Example

## Prompt
"Design a full observability stack for a distributed multi-agent platform with real-time anomaly detection, custom business metrics, SLO burn-rate alerting, distributed tracing across 10+ services, log aggregation with machine learning analysis, and automated incident correlation."

## Expected Behavior
The skill designs an enterprise observability architecture with OpenTelemetry instrumentation across all services, implements anomaly detection using metrics baselines, defines custom business KPI metrics, configures multi-window burn-rate alerting for SLOs, sets up log aggregation with ML-powered analysis for pattern detection, and implements automated incident correlation across traces, logs, and metrics.

## Expected Output
- observability-plan.md with enterprise-grade observability architecture
- OpenTelemetry configuration for all 10+ services with custom spans
- Anomaly detection rules with baseline definitions and sensitivity tuning
- Multi-window burn-rate alerting configuration with escalation policies
- Log aggregation pipeline with ML analysis configuration
- Automated incident correlation rules linking traces, logs, and metrics
- Custom Grafana dashboards for operations, business KPIs, and SLO tracking
