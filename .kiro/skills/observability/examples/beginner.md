# Beginner Example

## Prompt
"Design basic observability for a simple chatbot agent including logging and a health check endpoint."

## Expected Behavior
The skill identifies the chatbot as the single observable component, defines a basic structured logging strategy with request/response logging, configures a simple health check endpoint, and produces a minimal observability plan.

## Expected Output
- observability-plan.md with basic logging and health check strategy
- Logging configuration with structured JSON format and correlation ID
- Health check definition for the agent endpoint
- Basic metrics (request count, latency, error rate)
