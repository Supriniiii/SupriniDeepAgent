# Prompt Engineering Checklist

- [ ] All workflow reasoning points identified and mapped to prompts
- [ ] System prompt defines agent identity, capabilities, constraints, and behavioral guidelines
- [ ] Planning prompts support task decomposition with structured output
- [ ] Reflection prompts include quality criteria and clear pass/fail thresholds
- [ ] Context assembly respects model token limits with defined overflow strategy
- [ ] Output formats are parseable by downstream components with examples provided
- [ ] Model routing defined for all prompts with cost-appropriate assignment
- [ ] Every prompt has: purpose, inputs, outputs, constraints, examples, evaluation criteria
- [ ] All prompts are versioned and externalized from implementation code
- [ ] Evaluation test cases cover happy paths, edge cases, and failure modes
