# Advanced Example

## Prompt
"Design enterprise security for a distributed multi-agent platform processing PII data, requiring SOC2 and GDPR compliance, zero-trust network architecture, hardware security module integration for key management, automated threat detection, and security incident response automation."

## Expected Behavior
The skill designs a comprehensive zero-trust security architecture with mutual TLS between all services, integrates HSM for cryptographic key management, implements automated threat detection using behavioral analysis, designs data protection controls satisfying both SOC2 and GDPR requirements, configures automated security incident response playbooks, and produces a complete compliance evidence package.

## Expected Output
- security-requirements.md with enterprise controls mapped to SOC2 and GDPR requirements
- Zero-trust authentication with mTLS, service mesh integration, and identity federation
- Fine-grained authorization with ABAC policies, PII access controls, and data masking
- HSM integration configuration for key management with automatic rotation
- Automated threat detection rules with behavioral baselines and anomaly triggers
- Security incident response playbooks with automated containment and notification
- Compliance evidence package with control mapping and audit trail
