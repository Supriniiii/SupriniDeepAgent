# Advanced Example

## Prompt
"Generate a comprehensive test suite for a distributed planning agent system including performance tests under 1000 concurrent users, security penetration tests, chaos engineering scenarios for resilience testing, and LLM evaluation tests for prompt quality."

## Expected Behavior
The skill designs a multi-layered test strategy covering unit, integration, workflow, performance, security, resilience, and AI evaluation dimensions. It generates load test scripts with ramp-up profiles, security test cases targeting authentication and authorization, chaos scenarios simulating network partitions and service failures, and LLM evaluation frameworks measuring prompt effectiveness.

## Expected Output
- test-plan.md with enterprise-grade multi-dimensional test strategy
- Unit and integration test suites for all components
- Performance test scripts with load profiles (100, 500, 1000 concurrent users)
- Security test suite covering OWASP top 10 and agent-specific vulnerabilities
- Chaos engineering scenarios with expected recovery behaviors
- LLM evaluation framework with golden datasets and scoring rubrics
