# Beginner Example

## Prompt
"Generate unit tests for a simple prompt-response agent that answers FAQ questions."

## Expected Behavior
The skill analyzes the agent's single-component architecture, identifies testable functions (prompt construction, response parsing, intent classification), and generates a focused unit test suite covering happy paths and basic error cases.

## Expected Output
- test-plan.md with unit-level test strategy
- Unit test files covering prompt construction, response parsing, and error handling
- Test fixtures with sample FAQ data
- Test execution instructions
