# Advanced Example

## Prompt
"Perform full production-readiness validation of a distributed multi-agent system against enterprise governance policies, SOC2 compliance requirements, performance SLOs, and security hardening standards. Include regression comparison against previous validation."

## Expected Behavior
The skill performs exhaustive validation across all dimensions with enterprise rigor, validates SOC2 compliance controls, checks performance against defined SLOs, verifies security hardening checklist completion, performs regression analysis against previous validation results, and produces a governance-ready report package suitable for change advisory board review.

## Expected Output
- validation-report.md with enterprise-grade per-dimension assessment and evidence chain
- compliance-report.md covering SOC2 controls, security standards, and governance policies
- traceability-matrix.md with bidirectional tracing from requirements through testing
- production-readiness.md with formal go/no-go verdict, risk assessment, and sign-off sections
