# Beginner Example

## Prompt
"Validate a simple chatbot agent to confirm it meets basic engineering standards."

## Expected Behavior
The skill checks basic validation dimensions: requirements are met, architecture is documented, code follows standards, basic security is in place, and documentation exists. Produces a simple pass/fail report with any remediation items.

## Expected Output
- validation-report.md with per-dimension pass/fail results
- compliance-report.md confirming basic engineering standards adherence
- traceability-matrix.md mapping requirements to implementation
- production-readiness.md with basic readiness verdict
