# Intermediate Example

## Prompt
"Validate a multi-component research agent including architecture review, security validation, test coverage analysis, and documentation completeness check."

## Expected Behavior
The skill performs comprehensive validation across all dimensions, checks architecture patterns and component boundaries, validates security controls including authentication and secrets management, analyzes test coverage gaps, and verifies documentation completeness. Produces a detailed report with prioritized remediation items.

## Expected Output
- validation-report.md with detailed per-dimension analysis and evidence
- compliance-report.md covering engineering standards and security policies
- traceability-matrix.md with full requirement-to-implementation mapping
- production-readiness.md with conditional approval and blocking items listed
