# Reference Examples

## Purpose

This directory contains complete end-to-end reference implementations that combine multiple engineering standards into working solutions.

These examples demonstrate best practices for common engineering scenarios and serve as templates for Kiro when generating similar solutions.

---

# Contents

| File | Description |
|------|-------------|
| end-to-end-rag.ipynb | Complete RAG pipeline from embedding to retrieval to generation |
| chat-agent.ipynb | Conversational agent using Azure OpenAI and LangChain |
| embedding-demo.ipynb | Document embedding and similarity search with ChromaDB |

---

# Engineering Principles

- Examples should combine multiple standards into realistic workflows.
- Examples should demonstrate secure authentication.
- Examples should be runnable with appropriate credentials.
- Examples should include documentation explaining the approach.
- Examples should follow the same coding standards as production code.

---

# Usage

When generating end-to-end solutions, Kiro should reference these examples to understand how individual standards combine into complete engineering workflows.
