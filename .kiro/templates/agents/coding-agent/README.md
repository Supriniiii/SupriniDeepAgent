# Coding Agent Template

## Purpose

The Coding Agent Template extends the Generic Agent Template to provide a specialized blueprint for software engineering Deep Agents.

It defines the additional capabilities, workflows, tools, memory strategies, and prompts required for agents that analyze, generate, modify, test, and maintain software systems.

---

# Specialization

The Coding Agent adds:

- Repository analysis capabilities.
- Multi-file code generation.
- Code review workflows.
- Test generation.
- Refactoring support.
- Static analysis integration.
- Build system coordination.
- IDE integration.
