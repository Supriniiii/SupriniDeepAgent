# Data Agent Template

## Purpose

The Data Agent Template extends the Generic Agent Template to provide a specialized blueprint for data engineering Deep Agents.

It defines the additional capabilities, workflows, tools, memory strategies, and prompts required for agents that ingest, transform, validate, analyze, and deliver data.

---

# Specialization

The Data Agent adds:

- Data ingestion from multiple sources.
- Data transformation and processing.
- Data validation and quality assessment.
- Data pipeline orchestration.
- Analytics and reporting.
- Schema management.
- ETL/ELT pipeline support.
- Data governance compliance.
