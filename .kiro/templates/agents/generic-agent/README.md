# Generic Agent Template

## Purpose

The Generic Agent Template provides the foundational blueprint for all Deep Agents generated by the Deep Agent Engineering Platform (DAEP).

It defines the common engineering structure, runtime responsibilities, lifecycle, configuration, and operational behavior shared by every agent, regardless of its specialization.

All specialized agent templates, such as Coding Agents, Research Agents, Workflow Agents, and Data Agents, extend this template by adding domain-specific capabilities while preserving the core engineering principles defined here.

---

# Objectives

The Generic Agent Template aims to:

- Provide a common foundation for all agents.
- Standardize agent structure.
- Promote modularity and reuse.
- Support extensibility through specialization.
- Enable deterministic engineering.
- Simplify maintenance.
- Improve interoperability.
- Ensure enterprise-ready design.

---

# Scope

This template defines the common elements of a Deep Agent, including:

- Identity and metadata.
- Objectives.
- Responsibilities.
- Architecture.
- Runtime components.
- Workflow execution.
- Memory management.
- Prompt strategy.
- Tool integration.
- Evaluation criteria.
- Deployment considerations.

It intentionally excludes domain-specific behaviors, which belong in specialized templates.

---

# Summary

The Generic Agent Template provides the reusable engineering foundation for every Deep Agent within DAEP.

By defining a standardized architecture, lifecycle, runtime components, and engineering principles, it ensures that all generated agents remain consistent, extensible, maintainable, and enterprise-ready while allowing specialized templates to build upon a common foundation.
