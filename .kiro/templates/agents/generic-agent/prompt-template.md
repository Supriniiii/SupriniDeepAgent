# Prompt Validation

The generated prompt package must satisfy the following:

- Every prompt has a clearly defined purpose.
- Prompt responsibilities do not overlap.
- Context assembly is deterministic.
- Memory injection strategy is documented.
- Model routing is specified.
- Output formats are validated.
- All prompts support the approved workflow.
- Governance requirements are satisfied.
