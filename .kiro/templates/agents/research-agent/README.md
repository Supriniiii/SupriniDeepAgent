# Research Agent Template

## Purpose

The Research Agent Template extends the Generic Agent Template to provide a specialized blueprint for research-oriented Deep Agents.

It defines the additional capabilities, workflows, tools, memory strategies, and prompts required for agents that discover, analyze, compare, synthesize, and report information from multiple sources.

---

# Specialization

The Research Agent adds:

- Multi-source information gathering.
- Evidence-based reasoning.
- Source validation and credibility assessment.
- Knowledge synthesis.
- Citation management.
- Structured report generation.
- Iterative research refinement.
