# Purpose

Creates, stores, and restores execution checkpoints at significant milestones, enabling reliable recovery, resumption of long-running processes, and preservation of engineering progress.

---

# Responsibilities

- Create checkpoints at milestones.
- Store checkpoint data reliably.
- Restore checkpoints on recovery.
- Manage checkpoint retention.
- Validate checkpoint integrity.
- Support incremental checkpoints.
- Clean up obsolete checkpoints.

---

# Scope

Covers checkpoint creation and restoration. Does not manage general execution state, session lifecycle, or recovery decision logic.

# State Management

Maintains checkpoint catalog, integrity hashes, retention schedules, and restoration history.

---

# Error Handling

If checkpoint creation fails, retry once. If restoration fails, fall back to nearest valid checkpoint. Never proceed with corrupted state.

---

# Logging

Logs checkpoint creation, restoration, retention enforcement, and integrity verification results.

---

# Monitoring

Exposes checkpoint count, creation latency, restoration success rate, and storage utilization.

---

# Validation Requirements

- Checkpoints pass integrity checks.
- Restoration produces valid state.
- Retention policies enforced.
- No data loss during checkpointing.
