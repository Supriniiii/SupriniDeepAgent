# Purpose

Assembles, manages, and optimizes runtime context for prompt construction by combining information from multiple sources according to priority rules, size constraints, and relevance criteria.

---

# Responsibilities

- Assemble context from multiple sources.
- Apply priority ordering.
- Enforce context size limits.
- Compress context when needed.
- Inject memory into context.
- Manage context freshness.
- Optimize context relevance.
- Support context versioning.

---

# Scope

Covers context assembly and optimization. Does not store memory, execute prompts, or make engineering decisions.

# State Management

Maintains current context assembly state, source metadata, and compression history.

---

# Error Handling

If a source is unavailable, assemble context from remaining sources and flag gaps. Never fail completely due to a single missing source.

---

# Logging

Logs context assembly decisions, source usage, compression actions, and size utilization.

---

# Monitoring

Exposes context size, source count, compression ratio, assembly latency, and freshness metrics.

---

# Validation Requirements

- Context does not exceed size limits.
- Priority ordering is respected.
- Required sources are included.
- Context is internally consistent.
