# Purpose

Coordinates all memory operations across memory types, providing a unified interface for storing, retrieving, updating, and deleting information while managing memory lifecycle, governance, and persistence.

---

# Responsibilities

- Coordinate memory operations across all memory types.
- Route requests to appropriate memory stores.
- Manage memory lifecycle.
- Enforce retention policies.
- Validate memory operations.
- Support memory governance.
- Coordinate persistence and recovery.
- Provide unified memory interface.

---

# Scope

Covers memory coordination and lifecycle management. Does not implement specific storage technologies or perform business logic.
