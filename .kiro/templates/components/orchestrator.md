# Purpose

Provides high-level orchestration of multiple components, workflows, and engineering processes, coordinating the complete execution lifecycle from request to delivery without performing engineering work directly.

---

# Responsibilities

- Coordinate component interactions.
- Manage execution lifecycle.
- Route requests to components.
- Monitor execution progress.
- Handle cross-component failures.
- Produce execution summaries.
- Enforce orchestration policies.

---
