# Purpose

Measures runtime performance characteristics including latency, throughput, resource utilization, and execution efficiency to ensure generated solutions meet operational performance requirements.

---

# Responsibilities

- Collect execution timing metrics.
- Measure throughput and processing rates.
- Track resource utilization.
- Identify performance bottlenecks.
- Compare against performance baselines.
- Generate performance reports.
- Recommend performance optimizations.

---

# Scope

Covers runtime performance measurement only. Does not evaluate engineering quality, functional correctness, or business value.

# Error Handling

If metrics collection fails, log warning and produce partial report. Never block execution due to performance measurement failures.
