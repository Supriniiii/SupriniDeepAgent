# Purpose

Handles failure recovery by detecting failures, selecting recovery strategies, restoring execution from checkpoints, and coordinating resumption while preserving engineering artifacts and execution integrity.

---

# Responsibilities

- Detect execution failures.
- Select recovery strategy.
- Coordinate checkpoint restoration.
- Resume execution from recovery point.
- Preserve engineering artifacts.
- Record recovery actions.
- Escalate unrecoverable failures.

---

# Scope

Covers failure recovery coordination. Does not create checkpoints, manage general state, or perform workflow logic.

# Error Handling

If recovery fails after max attempts, escalate to human. Preserve all artifacts and state information for manual inspection.
