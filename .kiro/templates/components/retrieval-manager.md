# Purpose

Handles intelligent information retrieval from memory stores by executing queries, ranking results, applying relevance scoring, managing freshness, and assembling retrieved information for downstream consumption.

---

# Responsibilities

- Execute retrieval queries.
- Rank results by relevance.
- Apply freshness weighting.
- Filter results by criteria.
- Deduplicate results.
- Assemble retrieval packages.
- Track retrieval effectiveness.
- Support multiple retrieval strategies.

---

# Scope

Covers information retrieval and ranking. Does not store data, manage memory lifecycle, or construct prompts.
