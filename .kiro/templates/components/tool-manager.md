# Purpose

Discovers, selects, authenticates, and coordinates tool invocations, providing a unified interface between Deep Agents and external services while enforcing security, governance, and operational policies.

---

# Responsibilities

- Discover available tools.
- Select appropriate tools.
- Manage authentication.
- Coordinate tool invocations.
- Handle tool responses.
- Manage tool failures.
- Enforce security policies.
- Record tool usage metrics.

---

# Scope

Covers tool coordination and management. Does not implement tools or perform business logic through tools.

# State Management

Maintains active tool sessions, invocation queue, retry state, and usage metrics.

---

# Error Handling

Retry transient failures, select alternative tools when primary fails, escalate persistent failures, never expose raw tool errors externally.

---

# Logging

Logs tool selection, invocations, responses, failures, retries, and security events.

---

# Monitoring

Exposes tool usage rates, success/failure ratios, latency, retry counts, and security violations.

---

# Validation Requirements

- Tool is available and authorized.
- Response is valid and complete.
- Security policies satisfied.
- Rate limits respected.
- Audit records created.
