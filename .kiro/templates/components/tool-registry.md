# Purpose

Maintains a catalog of available tools with their metadata, capabilities, configuration requirements, and access policies, enabling tool discovery and selection by the Tool Manager.

---

# Responsibilities

- Register available tools.
- Maintain tool metadata.
- Support tool discovery.
- Track tool availability.
- Manage tool versions.
- Enforce tool governance.
- Provide tool capability descriptions.

---

# Scope

Covers tool cataloging and discovery. Does not invoke tools, select tools for specific tasks, or manage authentication.

# State Management

---

# Error Handling

If a tool becomes unavailable, update status and notify dependents. Never remove tools from registry without explicit action.

---

# Logging

Logs registrations, availability changes, discovery queries, and governance violations.

---

# Monitoring
