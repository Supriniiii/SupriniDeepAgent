# Purpose

Selects the most appropriate tool for a given task based on functional requirements, availability, performance characteristics, cost, security policies, and engineering constraints.

---

# Responsibilities

- Evaluate tool requirements.
- Match requirements to available tools.
- Apply selection criteria.
- Consider cost and performance.
- Enforce security policies.
- Return optimal tool selection.
- Support fallback selection.

---

# Scope

Covers tool selection logic only. Does not invoke, register, or manage tools.

# Error Handling
