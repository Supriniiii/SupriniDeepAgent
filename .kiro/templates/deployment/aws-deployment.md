# Deployment Procedure

```text
1. Provision VPC with public/private subnets across availability zones
2. Deploy EKS cluster with managed node groups and IAM OIDC provider
3. Configure ECR repository and push application container images
4. Install AWS Load Balancer Controller and ExternalDNS
5. Deploy Secrets Store CSI Driver with AWS provider
6. Apply Kubernetes manifests (Deployment, Service, Ingress)
7. Configure ALB Ingress with ACM certificate and Route53 DNS
8. Enable CloudWatch Container Insights and X-Ray tracing
9. Validate pod IAM roles via IRSA (IAM Roles for Service Accounts)
10. Run end-to-end tests against ALB endpoint
```
