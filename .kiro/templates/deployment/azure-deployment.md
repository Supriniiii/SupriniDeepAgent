# Deployment Procedure

```text
1. Provision Azure resource group and networking (VNet, subnets, NSGs)
2. Deploy AKS cluster with managed identity and RBAC enabled
3. Configure ACR and attach to AKS for image pulling
4. Deploy Azure Key Vault and configure CSI secrets driver
5. Apply Kubernetes manifests (Deployment, Service, Ingress)
6. Configure Application Gateway Ingress Controller (AGIC)
7. Set up Azure Monitor container insights and Log Analytics
8. Configure Azure DNS records for external access
9. Run health checks and validate end-to-end connectivity
10. Enable Azure Policy for compliance enforcement
```

# Validation

- AKS cluster is running and nodes are in Ready state
- Pods pull images from ACR without authentication errors
- Key Vault secrets are mounted in pods via CSI driver
- Application Gateway routes traffic to backend pods
- Azure Monitor shows container metrics and logs flowing
