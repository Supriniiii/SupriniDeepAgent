# Deployment Procedure

```text
1. Stage 1 (Build): Compile source, run linting, produce build artifacts
2. Stage 2 (Test): Execute unit tests, integration tests, publish results
3. Stage 3 (Security): Run WhiteSource/Mend scan, OWASP dependency check
4. Stage 4 (Package): Build container image, push to ACR
5. Stage 5 (Deploy Staging): Deploy to AKS staging, run smoke tests
6. Approval Gate: Require manual approval for production deployment
7. Stage 6 (Deploy Production): Deploy to AKS production with rolling update
8. Post-Deployment: Run production health checks and notify stakeholders
```
