# Deployment Procedure

```text
1. Checkout source code at specified commit SHA
2. Restore dependency cache from previous builds
3. Install/resolve dependencies with integrity verification
4. Run static analysis and linting rules
5. Compile source code to target output format
6. Execute unit test suite with coverage instrumentation
7. Generate SBOM (Software Bill of Materials)
8. Package build artifacts (container image, binary, archive)
9. Sign artifacts with code-signing key
10. Publish signed artifacts to artifact registry with version tag
```

---

# Validation

- Build produces deterministic output for same commit (reproducible)
- All dependencies pass integrity and license compliance checks
- Unit tests pass with coverage above configured threshold
- Static analysis reports zero critical or high severity issues
- Published artifacts are signed and verifiable
