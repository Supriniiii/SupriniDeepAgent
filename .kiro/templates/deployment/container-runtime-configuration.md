# Deployment Procedure

```text
1. Select container runtime class (runc, gVisor, Kata) based on workload security needs
2. Configure cgroup v2 resource limits for CPU, memory, PIDs, and I/O
3. Apply security context: drop all capabilities, set non-root user, read-only rootfs
4. Mount secrets as tmpfs volumes at /run/secrets with restricted permissions
5. Configure log driver and structured output format
6. Set graceful shutdown signal (SIGTERM) and stop grace period
7. Apply seccomp and AppArmor profiles for syscall filtering
8. Configure restart policy and OOM score adjustment
9. Start container with validated runtime configuration
```

---

# Validation

- Container starts with non-root user (UID {{runtime_uid}})
- Root filesystem is mounted read-only (writes fail outside /tmp and /run)
- Memory limit enforcement triggers OOM kill at configured threshold
- Dropped capabilities prevent privilege escalation
- Seccomp profile blocks unauthorized syscalls without application errors
