# Deployment Procedure

```text
1. Create .env file from .env.example with local configuration
2. Pull latest images for all services (docker compose pull)
3. Build application image from local Dockerfile
4. Start infrastructure services first (database, cache, broker)
5. Wait for health checks on infrastructure services to pass
6. Run database migrations via one-off migration service
7. Start application services with dependency ordering
8. Verify all services report healthy via docker compose ps
9. Confirm inter-service communication on internal network
```
