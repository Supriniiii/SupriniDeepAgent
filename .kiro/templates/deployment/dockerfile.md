# Deployment Procedure

```text
1. Select minimal base image ({{base_image}}) with pinned digest
2. Stage 1: Install production dependencies with layer caching
3. Stage 2: Copy source code and execute build/compilation step
4. Stage 3: Copy built artifacts into clean production base image
5. Create non-root user and set as container runtime user
6. Configure HEALTHCHECK instruction with endpoint and interval
7. Set ENTRYPOINT and CMD for proper signal handling
8. Build image with build-args for version labels and metadata
9. Scan image with vulnerability scanner (Trivy/Snyk)
10. Push tagged image to container registry ({{container_registry}})
```
