# Deployment Procedure

```text
1. Trigger: Push to main branch or manual workflow_dispatch
2. Job 1 (build): Checkout code, setup runtime, install dependencies, compile
3. Job 2 (test): Run unit tests, integration tests, generate coverage report
4. Job 3 (security): Run SAST scan, dependency audit, secret detection
5. Job 4 (container): Build Docker image, scan for vulnerabilities, push to registry
6. Job 5 (deploy-staging): Deploy to staging environment, run smoke tests
7. Job 6 (deploy-production): Await approval gate, deploy to production
8. Post-deploy: Run end-to-end tests, notify team on success/failure
9. Artifact: Upload test reports, coverage, and SBOM as workflow artifacts
10. Cleanup: Remove temporary resources and expired artifacts
```

# Validation

- Workflow triggers correctly on configured events (push, PR, dispatch)
- All jobs complete within configured timeout limits
- Security scan blocks deployment on critical vulnerabilities
- Environment protection rules require approval for production
- Deployment artifacts are signed and stored with proper retention
