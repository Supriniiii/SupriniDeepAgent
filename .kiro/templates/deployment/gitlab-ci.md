# Deployment Procedure

```text
1. Stage: build - Compile source, generate build artifacts, cache dependencies
2. Stage: test - Run unit tests with coverage, publish JUnit reports
3. Stage: security - SAST, DAST, dependency scanning, container scanning
4. Stage: package - Build Docker image, push to GitLab Container Registry
5. Stage: deploy-staging - Deploy via GitLab Agent for Kubernetes
6. Staging Verification: Run integration tests against staging environment
7. Manual Gate: Require manual play action for production deployment
8. Stage: deploy-production - Deploy to production with environment tracking
9. Post-deploy: Create release, tag image, update changelog
```
