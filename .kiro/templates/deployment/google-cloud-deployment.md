# Deployment Procedure

```text
1. Create GCP project and enable required APIs (GKE, Artifact Registry, Secret Manager)
2. Provision VPC network with private subnets and Cloud NAT
3. Deploy GKE cluster with Workload Identity and network policy enforcement
4. Configure Artifact Registry and push container images
5. Set up Workload Identity binding for pod service accounts
6. Deploy application manifests (Deployment, Service, Ingress)
7. Configure Google-managed TLS certificate and Cloud Load Balancer
8. Enable Cloud Monitoring and Cloud Logging for GKE
9. Configure Cloud DNS records for external endpoints
10. Run validation tests against live deployment
```

---

# Validation

- GKE cluster nodes are Ready with Workload Identity enabled
- Pods authenticate to GCP services via Workload Identity (no key files)
- Secret Manager values are accessible in pods via CSI driver
- Cloud Load Balancer serves traffic with valid managed TLS certificate
- Cloud Monitoring dashboard shows application metrics
