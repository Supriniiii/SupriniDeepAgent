# Deployment Procedure

```text
1. Initialize IaC workspace with remote state backend configuration
2. Download and validate provider plugins and module dependencies
3. Run plan to generate change set showing additions, modifications, deletions
4. Review plan output for unintended resource changes or deletions
5. Execute policy-as-code checks (Sentinel, OPA, or Checkov)
6. Apply changes with auto-approve (CI) or manual confirmation (local)
7. Verify state is consistent with applied resources
8. Export outputs for downstream consumption (DNS names, IPs, ARNs)
9. Run drift detection to confirm no out-of-band changes
10. Commit lock file and state reference updates to version control
```

# Validation

- Plan produces zero unexpected changes (no drift from desired state)
- Policy checks pass with no critical violations
- Applied resources match plan exactly (no partial applies)
- State file is encrypted and accessible only by authorized principals
- Drift detection shows zero unmanaged changes
