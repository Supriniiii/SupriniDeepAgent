# Deployment Procedure

```text
1. Stage: Checkout - Pull source from SCM with clean workspace
2. Stage: Build - Compile application, resolve dependencies (with cache)
3. Stage: Test - Execute unit tests, publish JUnit XML results
4. Stage: Security - Run OWASP dependency check, SonarQube analysis
5. Stage: Package - Build Docker image, push to registry with build tag
6. Stage: Deploy Staging - Apply Kubernetes manifests to staging cluster
7. Stage: Integration Test - Run smoke tests against staging environment
8. Input: Manual approval gate for production deployment
9. Stage: Deploy Production - Rolling deploy to production cluster
10. Post: Archive artifacts, send notifications, clean workspace
```
