# Deployment Procedure

```text
1. Validate deployment manifest against cluster API version
2. Apply namespace and RBAC prerequisites (ServiceAccount, Role, RoleBinding)
3. Create or update ConfigMap and Secret resources
4. Apply PodDisruptionBudget for availability guarantees
5. Apply Deployment manifest with kubectl apply
6. Monitor rollout status (kubectl rollout status deployment/{{app_label}})
7. Verify desired replica count matches available replicas
8. Confirm all pods pass readiness and liveness probes
9. Validate service endpoint registration in kube-dns
10. Run post-deployment smoke tests against cluster endpoint
```

---

# Validation

- Deployment rollout completes within {{progress_deadline}} seconds
- All pods reach Running state with Ready condition = True
- Readiness probe succeeds on all replicas within health check interval
- Pod anti-affinity distributes replicas across availability zones
- Resource requests are honored by scheduler without pending pods
