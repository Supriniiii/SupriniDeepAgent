# Purpose

Defines Kubernetes Horizontal Pod Autoscaler (HPA) resources that automatically scale pod replicas based on CPU utilization, memory usage, custom metrics, or external metrics. This template configures scaling behaviors, stabilization windows, and metric targets to maintain application performance under variable load.

# Deployment Procedure

```text
1. Verify metrics-server is deployed and reporting pod metrics
2. Confirm target Deployment exists with resource requests defined
3. Configure custom metrics adapter if using non-standard metrics
4. Apply HPA resource with metric targets and scaling behaviors
5. Verify HPA reports current metrics (not <unknown>)
6. Load test to confirm scale-up triggers at configured threshold
7. Validate scale-down behavior respects stabilization window
8. Confirm PodDisruptionBudget prevents aggressive scale-down
9. Monitor HPA events for scaling decisions and conditions
```

---

# Validation

- HPA reports TARGETS with actual metric values (not <unknown>)
- Scale-up occurs when metric exceeds target by configured margin
- Scale-down respects stabilization window (no flapping)
- Replica count stays within min/max bounds under all conditions
- Custom metrics are correctly read from metrics adapter
