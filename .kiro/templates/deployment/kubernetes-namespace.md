# Deployment Procedure

```text
1. Create Namespace resource with team and environment labels
2. Apply ResourceQuota to enforce CPU, memory, and object count limits
3. Apply LimitRange to set default container resource constraints
4. Create default NetworkPolicy (deny all ingress/egress)
5. Apply service-specific NetworkPolicy allow rules
6. Create RBAC RoleBinding for team access
7. Deploy image pull secrets for container registry access
8. Verify namespace is active and quotas are enforced
```

---

# Validation

- Namespace is created and in Active phase
- ResourceQuota is applied and reports current usage correctly
- LimitRange injects default limits into pods without explicit requests
- Network policies block cross-namespace traffic by default
- RBAC bindings allow team members appropriate access level
