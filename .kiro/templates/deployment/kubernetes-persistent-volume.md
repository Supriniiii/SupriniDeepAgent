# Purpose

Defines Kubernetes PersistentVolume (PV) and PersistentVolumeClaim (PVC) resources for providing durable storage to stateful Deep Agent workloads. This template configures storage classes, access modes, capacity, reclaim policies, and volume expansion for database, cache, and artifact storage needs.

# Deployment Procedure

```text
1. Create or verify StorageClass with desired provisioner and parameters
2. Define PersistentVolumeClaim with access mode and capacity request
3. Apply PVC to target namespace
4. Verify volume is dynamically provisioned and bound
5. Configure pod spec to reference PVC in volumes section
6. Mount volume at specified container path with read/write permissions
7. Validate data persistence across pod restarts
8. Configure volume snapshot schedule for backup
9. Set up capacity monitoring and expansion alerts
```

---

# Validation

- PVC transitions to Bound state within provisioning timeout
- Pod successfully mounts volume at configured path
- Data written to volume persists across pod deletion and recreation
- Volume expansion succeeds without data loss when capacity increased
- Storage performance meets IOPS and latency targets
