# Deployment Procedure

```text
1. Validate service manifest YAML against Kubernetes API schema
2. Confirm target pods exist with matching label selector
3. Apply Service resource to the target namespace
4. Verify ClusterIP assignment (or LoadBalancer provisioning)
5. Confirm endpoints are populated with pod IPs
6. Test DNS resolution of service name within cluster
7. Validate port mapping from service port to container targetPort
8. For LoadBalancer type: confirm external IP assignment
9. Run connectivity test from another pod to the service endpoint
```

---

# Validation

- Service has assigned ClusterIP (non-headless) or resolves to pod IPs (headless)
- Endpoints object contains IP addresses for all ready pods
- DNS resolution of {{service_name}}.{{namespace}}.svc.cluster.local succeeds
- Traffic is load-balanced across all healthy pod endpoints
- Port mappings correctly route external port to container targetPort
