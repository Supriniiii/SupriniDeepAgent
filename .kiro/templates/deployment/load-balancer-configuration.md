# Deployment Procedure

```text
1. Provision load balancer in configured subnets (public or internal)
2. Configure listeners with SSL certificate and protocol settings
3. Create target group with backend health check configuration
4. Register backend instances/pods with target group
5. Configure routing rules for path-based or host-based routing
6. Enable access logging to storage destination
7. Configure connection draining for graceful backend removal
8. Test traffic distribution across all healthy backends
9. Validate SSL termination and certificate chain
```

---

# Validation

- Load balancer responds on configured ports with valid SSL
- Health checks correctly identify unhealthy backends and remove them
- Traffic distributes evenly across all registered healthy targets
- Connection draining allows in-flight requests to complete
- Access logs capture request details for all incoming traffic
