# Deployment Procedure

```text
1. Deploy time-series database with persistent storage and retention config
2. Configure service discovery for automatic metrics target detection
3. Define scrape configurations for application and infrastructure targets
4. Apply recording rules for pre-computed aggregations
5. Import dashboard templates for standard service metrics (RED/USE)
6. Configure SLO-based alerting rules
7. Set up remote write for long-term metric storage
8. Validate all targets are UP and scraping successfully
9. Create team-specific dashboards for key business metrics
```
