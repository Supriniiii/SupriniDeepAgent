# Deployment Procedure

```text
1. Provision VPC/VNet with configured CIDR block and availability zones
2. Create subnet tiers (public, private-app, private-data) with route tables
3. Deploy NAT Gateway for private subnet outbound access
4. Configure security groups/NSGs with least-privilege rules
5. Deploy load balancer in public subnet with TLS termination
6. Configure DNS zones and records for service endpoints
7. Enable VPC flow logs for network traffic analysis
8. Deploy network policies for Kubernetes pod-to-pod isolation
9. Test connectivity between tiers and validate security group rules
```

---

# Validation

- Subnets have correct CIDR ranges and no overlap
- Security groups block unauthorized traffic between tiers
- DNS resolution works for all configured service names
- Load balancer distributes traffic to healthy backends
- Flow logs capture traffic for security analysis
