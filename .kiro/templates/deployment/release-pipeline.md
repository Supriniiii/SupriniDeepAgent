# Deployment Procedure

```text
1. Select verified build artifact from artifact registry by version tag
2. Inject environment-specific configuration for target environment
3. Deploy to staging environment with automated health validation
4. Run integration tests and performance tests against staging
5. Await UAT approval (manual sign-off from QA team)
6. Deploy to UAT and execute acceptance test suite
7. Generate release notes and changelog from commit history
8. Await production approval (manual sign-off from release manager)
9. Deploy to production using configured release strategy
10. Verify production health, tag release in Git, notify stakeholders
```

---

# Validation

- Artifact version matches expected release version
- Each environment gate blocks until approval criteria are met
- Health checks pass in each environment before promotion
- Release notes accurately reflect changes since last release
- DORA metrics are captured for this release cycle
