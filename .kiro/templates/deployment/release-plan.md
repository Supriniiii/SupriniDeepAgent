# Deployment Procedure

```text
1. Pre-release: Verify all pre-conditions met (tests pass, approvals obtained)
2. Pre-release: Send stakeholder notification of upcoming deployment
3. Pre-release: Confirm on-call team availability and rollback readiness
4. Go/No-Go: Release manager confirms deployment window and criteria
5. Execute: Begin deployment using configured strategy
6. Monitor: Observe error rate and latency for observation period
7. Verify: Run post-deployment validation suite
8. Communicate: Send success/failure notification to stakeholders
9. Document: Record release outcome, metrics, and any incidents
10. Close: Close change ticket with release summary
```

---

# Validation

- All pre-conditions checklist items are verified before deployment begins
- Error rate remains below baseline + threshold during observation period
- Latency percentiles remain within SLO during and after deployment
- Post-deployment smoke tests pass within 5 minutes of completion
- No critical alerts fire during the observation window
