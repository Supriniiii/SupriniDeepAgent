# Purpose

This document tracks all notable changes to the project across releases, providing a chronological record of additions, modifications, deprecations, removals, bug fixes, and security patches. It enables stakeholders to understand what changed between versions and assess upgrade impact.

---

# Scope

This document covers version-by-version changes including new features, breaking changes, deprecations, bug fixes, and security updates. It does not cover internal refactors that have no user-facing impact or commit-level details already available in version control.

---

# Audience

- Users upgrading between versions
- Release managers preparing deployment notes
- Support teams diagnosing version-specific issues
- Stakeholders tracking feature delivery progress

---

# Prerequisites
