# Purpose

This document provides a complete reference for the REST API, including all available endpoints, HTTP methods, request/response schemas, authentication requirements, error codes, rate limits, and versioning strategy. It enables API consumers to integrate with the system programmatically.

---

# Scope

This document covers all public API endpoints, request parameters, response formats, status codes, pagination patterns, filtering options, error responses, and rate limiting. It does not cover internal service-to-service APIs, webhook implementations, or SDK-specific abstractions.
