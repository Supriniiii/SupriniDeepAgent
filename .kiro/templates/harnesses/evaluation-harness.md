# Purpose

The Evaluation Harness provides a structured assessment environment for measuring Deep Agent quality across dimensions including accuracy, relevance, safety, coherence, and task completion. It manages evaluation datasets, scoring rubrics, judge models, human annotation workflows, and statistical analysis to produce quantifiable quality metrics that inform agent improvement decisions.

---

# Runtime Overview

This harness operates an evaluation pipeline that runs agents against curated test datasets, collects outputs, applies scoring functions (automated and human-in-the-loop), and aggregates results into quality reports. It supports A/B comparison between agent versions, statistical significance testing, multi-dimensional rubric scoring, and regression detection. The runtime manages evaluation dataset versioning and scorer calibration.

# Error Handling

The Evaluation Harness treats agent failures on evaluation samples as valid data points (scored as failures) rather than infrastructure errors, ensuring evaluation completeness. Scorer failures (judge model timeouts, human annotator unavailability) trigger fallback to secondary scoring methods or queue samples for later evaluation. Dataset corruption or schema mismatches halt the evaluation run before any scoring begins to prevent invalid metrics.

# Validation Requirements

- Evaluation datasets must be versioned and immutable once an evaluation run begins
- Scoring rubrics must be calibrated against golden labels with inter-rater agreement thresholds
- Statistical significance must be established before declaring score differences meaningful
- A/B comparisons must use matched sampling to control for dataset difficulty variation
- Regression detection must flag score decreases that exceed the configured threshold with p-value reporting
