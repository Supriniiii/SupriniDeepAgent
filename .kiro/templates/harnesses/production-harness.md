# Purpose

The Production Harness provides a hardened, highly-available execution environment for Deep Agents serving live traffic and business-critical workloads. It enforces production-grade reliability standards including SLO management, incident response automation, capacity planning, disaster recovery, and operational runbook integration to ensure agents operate with the resiliency and observability required for production systems.

---

# Runtime Overview

This harness operates in a production-hardened configuration with multi-availability-zone deployment, automated failover, load balancing, rate limiting, and circuit breakers for all external dependencies. It provides SLO-driven alerting, on-call integration, automated incident classification, capacity forecasting, and change management controls. The runtime enforces immutable deployments, audit logging for all operations, and automated compliance verification.

# Error Handling

The Production Harness classifies errors by customer impact severity and routes them through the incident management system with automatic escalation based on SLO burn rate. Circuit breakers protect against cascading failures by isolating unhealthy dependencies and serving degraded responses rather than timing out. Every error generates a correlation ID that traces through all system components for rapid root-cause analysis during incidents.

# Validation Requirements

- All deployments must pass pre-production validation including load testing at expected peak traffic
- SLO targets must be defined, monitored, and alerting must fire before error budgets are exhausted
- Disaster recovery procedures must be tested quarterly with documented RTO/RPO verification
- Rate limiting must protect the system from traffic spikes without impacting legitimate users below threshold
- Change management approvals must be obtained and recorded before any production configuration changes
