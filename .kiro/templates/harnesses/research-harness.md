# Purpose

The Research Harness provides an information retrieval and synthesis execution environment for Deep Agents that gather, evaluate, and synthesize knowledge from multiple sources. It manages evidence collection pipelines, citation tracking, source credibility assessment, and structured report generation to enable agents that produce well-sourced, verifiable research outputs.

---

# Runtime Overview

This harness operates a retrieval-augmented runtime with access to search APIs, document stores, knowledge graphs, and citation databases. It orchestrates multi-source queries, deduplicates findings, tracks provenance chains, and maintains an evidence graph that links claims to supporting sources. The runtime enforces source diversity requirements and confidence scoring before allowing conclusions to be finalized.

# Error Handling

The Research Harness handles source unavailability by falling back to cached versions or alternative sources without halting the research pipeline. Conflicting evidence is flagged and presented with confidence scores rather than silently discarded. Rate-limited APIs trigger adaptive throttling with request queuing, and permanent source failures are recorded in the evidence graph as gaps requiring alternative coverage.

# Validation Requirements

- Every claim in generated output must be traceable to at least one cited source with provenance metadata
- Source credibility scores must meet the configured threshold before evidence is included in final outputs
- Research queries must be executed against a minimum number of independent sources for diversity
- Citation formats must conform to the specified standard (APA, IEEE, Chicago, or custom)
- Conflicting evidence must be explicitly acknowledged with confidence-weighted analysis
