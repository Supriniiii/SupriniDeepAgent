# Purpose

The Single Agent Harness provides an optimized execution environment for standalone Deep Agents operating independently without multi-agent coordination overhead. It delivers dedicated resource allocation, focused lifecycle management, and streamlined orchestration for agents that handle complete tasks autonomously within a single execution context.

---

# Runtime Overview

This harness operates a single-agent process with exclusive resource ownership, direct tool access, and simplified state management. The runtime eliminates inter-agent communication layers, providing lower latency and reduced complexity for workloads where one agent handles the full request-response cycle from planning through execution.

# Error Handling

The Single Agent Harness captures all exceptions within the agent execution loop and applies a decision tree to determine whether to retry, degrade, or terminate. Since no peer agents exist to absorb delegated work, the harness prioritizes checkpointing partial progress before any recovery attempt. Fatal errors trigger immediate state persistence followed by controlled shutdown with full diagnostic export.

# Validation Requirements

- The single agent must successfully complete its self-diagnostic routine before accepting tasks
- Memory allocation must not exceed the configured context window budget during execution
- Tool permissions must be validated against the agent's declared capability manifest
- Reflection loops must terminate within the configured maximum reasoning steps
- Checkpoint frequency must be sufficient to limit rework on recovery to acceptable thresholds

---

# Extension Points

- Custom reasoning strategies can replace the default planner-executor loop
- Reflection hooks allow injection of external evaluation between reasoning steps
- Tool adapters support hot-reload for adding capabilities without agent restart
- Output formatters can be registered to transform agent responses for downstream consumers
