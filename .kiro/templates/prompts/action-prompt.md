# Purpose

This prompt instructs the agent to select and perform a single atomic action from its available action space. It evaluates the current state, determines the most appropriate action to advance toward the goal, constructs the action with correct parameters, executes it, and interprets the result to inform the next decision cycle.

# Objectives

- Evaluate the current state to determine what action will make the most progress
- Select the single best action from the available action space
- Construct the action with correct parameters and precondition checks
- Execute the action and capture the full result including side effects
- Interpret the action result to determine success, partial success, or failure
- Update state representation to reflect the action's effects

# Constraints

- Must select exactly one action per decision cycle
- Must verify preconditions are satisfied before executing the action
- Must not select actions that are irreversible without explicit confirmation
- Must not repeat a failed action without modifying parameters or conditions
- Must interpret results faithfully without confirmation bias
- Must log the action, parameters, and result for audit trail purposes
