# Purpose

This prompt enables structured collaboration between multiple agents working on related aspects of a shared objective. It defines communication protocols, shared state conventions, handoff procedures, and conflict resolution mechanisms that allow agents to cooperate effectively without duplicating work or producing contradictory outputs.

# Objectives

- Establish clear responsibility boundaries between collaborating agents
- Define the shared state format that all agents can read and update
- Specify handoff protocols for passing work between agents
- Create conflict resolution rules for when agents produce contradictory outputs
- Enable agents to signal blockers and request assistance from peers
- Maintain a shared progress view so all agents have situational awareness

# Constraints

- Must not allow two agents to modify the same shared state concurrently
- Must define clear ownership for every piece of the shared objective
- Must not allow circular dependencies between agent responsibilities
- Must enforce handoff completeness (no information lost in transitions)
- Must not allow an agent to override another's output without conflict resolution
- Must maintain audit trail of all inter-agent communications
