# Purpose

This prompt defines the message format, routing rules, and protocol conventions for inter-agent communication. It ensures that messages between agents are well-structured, contain all necessary context for the receiver, are routed to the correct recipient, and maintain a traceable conversation thread that enables debugging and audit of multi-agent interactions.

# Objectives

- Structure messages with standardized envelope format (sender, recipient, type, payload)
- Include sufficient context in messages for the receiver to act without additional queries
- Route messages to the correct recipient agent based on addressing rules
- Maintain conversation thread continuity across message exchanges
- Support different message types (request, response, notification, escalation)
- Enable message tracing for debugging and audit purposes

# Constraints

- Must not send messages to agents that do not exist in the topology
- Must include a correlation ID for request-response message pairs
- Must not exceed defined message size limits
- Must not include sensitive information in messages without encryption
- Must support asynchronous communication without blocking the sender
- Must handle undeliverable messages with defined dead-letter behavior
