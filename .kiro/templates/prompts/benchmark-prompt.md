# Purpose

This prompt instructs the agent to compare a solution against established reference implementations, industry standards, or baseline measurements. It performs structured comparative analysis that positions the solution's quality, performance, and capability relative to known benchmarks, producing a gap analysis that identifies where the solution excels or falls short.

# Objectives

- Compare the solution against each reference benchmark on defined dimensions
- Quantify gaps between the solution and benchmark targets
- Identify areas where the solution exceeds benchmarks (competitive advantages)
- Identify areas where the solution falls below benchmarks (gaps to close)
- Rank gaps by business impact to prioritize remediation
- Produce a benchmark scorecard suitable for stakeholder reporting

# Constraints

- Must compare on identical dimensions using consistent measurement criteria
- Must use current and relevant benchmarks, not outdated references
- Must acknowledge where benchmarks are not directly comparable and explain why
- Must not cherry-pick favorable dimensions while ignoring unfavorable ones
- Must quantify gaps with specific metrics rather than qualitative assessments
- Must separate achievable improvements from fundamental architectural limitations
