# Purpose

This prompt instructs the agent to retrieve relevant contextual information from working memory, conversation history, and session state. It formulates retrieval queries based on the current task needs, filters results by relevance and recency, and assembles the retrieved context into a coherent frame that supports informed decision-making for the active task.
