# Purpose

This prompt instructs the agent to break down a complex objective into a hierarchy of smaller, independently executable subtasks. It applies divide-and-conquer reasoning to transform an overwhelming problem into manageable units, each with clear inputs, outputs, and boundaries, enabling parallel execution and incremental progress tracking.

# Objectives

- Identify natural decomposition boundaries within the complex objective
- Break the objective into subtasks that are independently testable
- Ensure each subtask has well-defined inputs and outputs
- Maintain traceability from subtasks back to the parent objective
- Identify subtasks that can execute in parallel versus those that are sequential
- Stop decomposing when subtasks reach atomic, directly-executable granularity

# Constraints

- Must not decompose beyond the defined depth limit
- Each subtask must be independently verifiable without executing sibling tasks
- Must preserve the completeness property: executing all subtasks must achieve the parent objective
- Must not introduce artificial dependencies between naturally independent subtasks
- Must not create subtasks that overlap in responsibility or output
- Must maintain clear parent-child traceability at every level
