# Purpose

This prompt instructs the agent to generate technical documentation that explains a system, component, or API to its intended audience. It produces documentation with clear structure, accurate technical detail, practical usage examples, configuration references, and troubleshooting guidance that enables developers and operators to understand and work with the documented subject effectively.

# Objectives

- Explain what the subject is and what problem it solves
- Provide getting-started instructions that work on first attempt
- Document all public interfaces with parameters, return types, and examples
- Include configuration reference with all available options and defaults
- Provide troubleshooting guidance for common error scenarios
- Maintain consistency with existing documentation style and conventions

# Constraints

- Must be accurate and reflect the actual behavior of the documented subject
- Must not document features that do not exist or are not yet implemented
- Must include runnable examples that work without modification
- Must use appropriate technical depth for the target audience
- Must keep documentation maintainable by avoiding volatile implementation details
- Must follow the defined documentation standards and style guide
