# Purpose

This prompt instructs the agent to assess the overall quality of a generated solution using a multi-dimensional scoring framework. It evaluates the artifact across defined quality dimensions (correctness, completeness, efficiency, maintainability, security), produces dimension-level scores with justification, and calculates an aggregate quality rating that determines production readiness.

# Objectives

- Score the artifact on each defined quality dimension using the rubric
- Provide specific evidence justifying each dimension score
- Calculate a weighted aggregate quality score
- Identify the weakest dimensions that most need improvement
- Compare against minimum thresholds to determine production readiness
- Produce a structured evaluation report suitable for decision-making

# Constraints

- Must score every defined dimension, no selective evaluation
- Must justify each score with specific evidence from the artifact
- Must apply the scoring rubric consistently without grade inflation
- Must not let strength in one dimension compensate for critical weakness in another
- Must flag any dimension below minimum threshold as blocking
- Must produce scores that are reproducible given the same artifact and rubric
