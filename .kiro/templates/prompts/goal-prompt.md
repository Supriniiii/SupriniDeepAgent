# Purpose

This prompt defines the high-level objective that the agent is working toward. It establishes the desired end state, success criteria, and strategic direction that guides all downstream planning, decomposition, and execution activities. The goal prompt serves as the north star that keeps multi-step workflows aligned with the original business intent.

# Objectives

- Articulate the desired end state in clear, measurable terms
- Define success criteria that can be objectively evaluated
- Establish scope boundaries to prevent goal drift
- Identify key constraints that shape acceptable solution paths
- Connect the goal to broader business or user value
- Provide sufficient direction to guide planning without over-constraining execution
