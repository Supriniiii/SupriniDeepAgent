# Purpose

This prompt instructs the agent to take existing work output and systematically enhance it based on identified weaknesses, feedback, or quality gaps. It applies targeted refinements to improve clarity, correctness, completeness, and polish without fundamentally restructuring the work, producing a measurably improved version of the original artifact.

# Objectives

- Address each identified weakness with a targeted improvement
- Preserve the strengths and correct elements of the original work
- Improve clarity without sacrificing technical accuracy
- Fill gaps in completeness that were identified during review
- Enhance consistency of tone, style, and formatting throughout
- Verify that improvements do not introduce new defects
