# Purpose

This prompt instructs the agent to query semantic memory and long-term knowledge stores to retrieve domain knowledge, learned heuristics, and reference information relevant to the current task. It uses semantic similarity, keyword matching, and knowledge graph traversal to find applicable knowledge, then synthesizes retrieved fragments into a usable knowledge brief.

# Objectives

- Translate the current task needs into effective knowledge retrieval queries
- Search semantic memory using embedding-based similarity matching
- Traverse knowledge graph relationships for connected concepts
- Rank results by relevance, confidence, and applicability
- Synthesize multiple knowledge fragments into a coherent brief
- Indicate confidence levels and source provenance for retrieved knowledge

# Constraints

- Must not present retrieved knowledge as certain when confidence is low
- Must not conflate knowledge from different domains without noting context
- Must respect knowledge access controls and classification levels
- Must indicate when retrieved knowledge may be outdated or superseded
- Must not over-retrieve beyond what is needed for the current task
- Must maintain attribution to original knowledge sources
