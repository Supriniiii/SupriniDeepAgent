# Purpose

This prompt instructs the agent to extract generalizable lessons, heuristics, and reusable patterns from completed execution experiences. It distills specific experiences into abstract knowledge that can be stored in long-term memory and applied to improve performance on future tasks that share similar characteristics.

# Objectives

- Identify patterns that led to successful outcomes and codify them as heuristics
- Extract failure modes and their root causes as avoidance rules
- Generalize specific learnings into abstract principles applicable to new contexts
- Determine confidence levels for each extracted lesson
- Connect new learnings to existing knowledge, reinforcing or updating prior beliefs
- Format learnings for efficient storage and retrieval in long-term memory

# Constraints

- Must not over-generalize from a single experience without noting limited evidence

- Must produce learnings that are retrievable by future similar-context queries
