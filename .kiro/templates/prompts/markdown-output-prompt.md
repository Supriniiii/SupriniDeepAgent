# Purpose

This prompt instructs the agent to render its output as well-formed Markdown that follows specific formatting conventions, heading hierarchy, list structure, code block usage, and table formatting rules. It ensures that generated Markdown renders correctly across different viewers, maintains consistent style, and is suitable for inclusion in documentation systems and knowledge bases.

# Objectives

- Structure content with proper heading hierarchy (H1 through H4 max)
- Use appropriate list types (ordered for sequences, unordered for collections)
- Format code blocks with correct language identifiers for syntax highlighting
- Construct tables with proper alignment and header separation
- Include links with descriptive text and valid references
- Maintain consistent spacing and formatting throughout the document

# Constraints

- Must not skip heading levels (no H1 directly to H3)
- Must use fenced code blocks with language identifiers, not indented blocks
- Must not use HTML tags when Markdown syntax is available
- Must limit line length to improve readability in plain text editors
- Must use relative links for internal references where applicable
- Must not include broken links or unresolvable references
