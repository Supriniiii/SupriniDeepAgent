# Purpose

This prompt instructs the agent to compress, organize, and optimize accumulated memory contents. It merges redundant entries, resolves contradictions between stored facts, promotes frequently-accessed working memory to long-term storage, evicts stale entries, and restructures memory indexes to maintain retrieval efficiency as the knowledge base grows.

# Objectives

- Identify and merge redundant memory entries preserving the most complete version
- Resolve contradictions between entries by determining which is authoritative
- Compress verbose entries into concise representations without information loss
- Promote high-value working memory entries to long-term storage
- Evict stale, low-value entries that consume capacity without providing benefit
- Rebuild retrieval indexes to maintain search performance after consolidation

# Constraints

- Must not lose critical information during compression or eviction
- Must resolve contradictions using defined authority hierarchies, not arbitrary choice
- Must preserve full provenance and audit trail for consolidated entries
- Must not consolidate entries that are actively referenced by running workflows
- Must verify consolidated memory is functionally equivalent to the pre-consolidation state
- Must not exceed defined consolidation time budgets
