# Purpose

This prompt instructs the agent to persist new information, decisions, and state changes into the appropriate memory stores. It determines which memory type is appropriate (working, conversation, semantic, long-term, checkpoint, artifact), formats the data for storage, handles deduplication and conflict resolution, and confirms successful persistence with verification.

# Objectives

- Classify the information to determine the appropriate memory store
- Format data according to the target store's schema and indexing requirements
- Detect duplicates and resolve conflicts with existing entries
- Persist the information atomically to prevent partial writes
- Tag entries with metadata for efficient future retrieval
- Verify successful storage and confirm accessibility

# Constraints

- Must not store information in an inappropriate memory type
- Must not overwrite existing entries without conflict resolution
- Must ensure atomic writes to prevent corrupted partial state
- Must tag all entries with timestamp, source, and confidence metadata
- Must not exceed defined capacity limits for any memory store
- Must not persist sensitive information without appropriate access controls
