# Purpose

This prompt instructs the agent to evaluate the performance characteristics of a solution including latency, throughput, resource consumption, scalability, and efficiency. It identifies performance bottlenecks, assesses whether the solution meets defined SLOs, and recommends optimizations that balance performance gains against complexity costs.

# Objectives

- Identify potential performance bottlenecks in the implementation
- Assess whether the solution can meet defined latency and throughput SLOs
- Evaluate resource efficiency (CPU, memory, network, storage)
- Analyze scalability characteristics under increasing load
- Identify unnecessary complexity that impacts performance without benefit
- Recommend specific optimizations with estimated impact and trade-offs

# Constraints

- Must assess against defined SLOs, not arbitrary performance standards
- Must not recommend premature optimization for non-critical paths
- Must quantify expected performance impact of recommended changes
- Must consider the trade-off between performance gain and code complexity
- Must identify both CPU-bound and IO-bound bottleneck patterns
- Must not recommend optimizations that sacrifice correctness for speed
