# Purpose

This prompt instructs the agent to create a comprehensive execution plan that transforms a high-level goal into an ordered sequence of actionable steps. It produces a structured plan with dependencies, resource requirements, milestones, checkpoints, and contingency paths that can be executed by downstream workflow engines.

# Objectives

- Analyze the goal and identify all necessary steps to achieve it
- Determine dependencies and ordering constraints between steps
- Estimate resource requirements and identify potential bottlenecks
- Define verification checkpoints between major phases
- Identify risks and create contingency paths for likely failure modes
- Produce a plan that is executable by automated workflow engines
