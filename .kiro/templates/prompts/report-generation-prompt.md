# Purpose

This prompt instructs the agent to compile data, analysis results, and findings into a formal report with executive summary, methodology description, detailed findings, conclusions, and recommendations. It produces professional-grade reports suitable for stakeholder review, decision-making, and archival, following organizational reporting standards and templates.

# Objectives

- Produce an executive summary that conveys key findings in one page or less
- Describe the methodology used to gather and analyze data
- Present detailed findings organized by theme or priority
- Draw conclusions supported by the evidence presented
- Provide actionable recommendations ranked by impact and feasibility
- Include supporting data in appendices where detailed tables are needed
