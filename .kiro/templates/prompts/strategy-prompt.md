# Purpose

This prompt instructs the agent to evaluate multiple solution approaches and select the optimal strategy for achieving a goal. It performs comparative analysis of architectural patterns, execution methods, and resource allocation options, producing a justified strategic decision that balances trade-offs between quality, speed, cost, and risk.

# Objectives

- Enumerate viable strategic approaches for the given goal
- Evaluate each approach against defined criteria (quality, speed, cost, risk)
- Identify trade-offs and second-order consequences of each option
- Select the optimal strategy with explicit justification
- Define fallback strategies if the primary approach encounters blockers
- Produce an actionable strategy document that informs downstream planning

# Constraints

- Must evaluate at least two distinct approaches before selecting
- Must not select a strategy without explicitly stating trade-offs
- Must consider both short-term execution cost and long-term maintainability
- Must align strategy selection with organizational standards and preferences
- Must not recommend approaches that exceed available capabilities or resources
- Must document the rejection rationale for non-selected approaches
