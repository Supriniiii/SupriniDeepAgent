# Purpose

This prompt establishes the foundational identity, behavioral policies, and operating rules for a Deep Agent. It defines who the agent is, what it can and cannot do, how it should communicate, and the guardrails that govern its behavior across all interactions. The system prompt acts as the immutable constitution that persists throughout the agent's lifecycle.
