# Purpose

This prompt instructs the agent to rank and order a set of tasks based on urgency, importance, dependencies, and resource availability. It applies prioritization frameworks to determine which tasks should be executed first, which can be deferred, and which can be parallelized, producing an optimized execution schedule that maximizes value delivery.

# Objectives

- Score each task against defined prioritization criteria
- Identify critical path tasks that block downstream work
- Separate urgent tasks from important but deferrable tasks
- Group parallelizable tasks for concurrent execution
- Produce a ranked execution order that maximizes throughput
- Flag tasks that should be dropped or deferred based on cost-benefit analysis

# Constraints

- Must not reorder tasks in a way that violates dependency constraints
- Must consider resource contention when scheduling parallel tasks
- Must apply consistent scoring criteria across all tasks
- Must not defer critical-path tasks regardless of their individual priority score
- Must surface tasks with unresolvable blockers rather than silently deprioritizing
- Must re-evaluate priority if new information changes the constraint landscape
