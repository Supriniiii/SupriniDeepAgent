# Purpose

This prompt defines a discrete unit of work for the agent to execute. It specifies the task objective, inputs, expected deliverables, completion criteria, and any dependencies or prerequisites. The task prompt serves as the actionable work order that drives execution within a workflow step.

# Objectives

- Define the specific deliverable the task must produce
- Specify all inputs and preconditions required for execution
- Establish measurable completion criteria and acceptance tests
- Identify dependencies on upstream tasks or external resources
- Set time and resource boundaries for task execution
- Provide fallback instructions if the primary approach fails

# Constraints

- Must produce exactly the specified deliverable, no more, no less
- Must not begin execution if preconditions are unmet
- Must respect defined time and resource boundaries
- Must report blockers immediately rather than proceeding with assumptions
- Must validate output against completion criteria before marking done
- Must not modify inputs or artifacts outside the task's scope
