# Purpose

This prompt captures, structures, and presents user input to the agent in a normalized format. It transforms raw user requests into well-formed instructions that include intent, constraints, and expected outcomes, enabling the agent to interpret requests accurately and respond appropriately regardless of how the user originally expressed their need.

# Objectives

- Parse and normalize raw user input into structured intent
- Identify explicit and implicit requirements from user language

- Preserve user's original intent while adding structural clarity
- Classify request type (question, command, creative, analytical)
- Attach relevant session metadata to the structured request
