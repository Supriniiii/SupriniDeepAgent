# Purpose

This prompt orchestrates the end-to-end execution of a multi-step workflow, managing transitions between steps, handling branching logic, coordinating parallel paths, enforcing timeouts, and ensuring the workflow reaches a terminal state. It acts as the conductor that keeps all workflow components synchronized and progressing toward completion.

# Objectives

- Advance the workflow from current state to the next valid state
- Evaluate branching conditions and select the correct path
- Coordinate parallel execution paths and manage join synchronization
- Enforce step-level and workflow-level timeouts
- Handle step failures according to defined error policies (retry, skip, abort)
- Persist workflow state at each transition for crash recovery

# Constraints

- Must follow the workflow definition exactly without skipping or reordering steps
- Must not advance past a step until its completion criteria are met
- Must enforce timeout limits and trigger timeout handlers when exceeded
- Must synchronize parallel paths before executing join steps
- Must persist state atomically at each transition to prevent corruption
- Must terminate the workflow in a defined terminal state (success, failure, timeout)
