# Purpose

Verifies that the memory strategy supports the approved workflow, context management is complete, retrieval and persistence strategies are defined, retention policies exist, and governance requirements are satisfied.

- Verify memory types are defined.
- Validate context management completeness.
- Confirm retrieval strategy documentation.
- Verify persistence strategy.
- Check retention policies.
- Validate governance compliance.
