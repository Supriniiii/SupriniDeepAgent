# Workflow Templates

## Purpose

The Workflow Templates directory contains reusable workflow blueprints used by the Deep Agent Engineering Platform (DAEP) to generate standardized execution workflows for Deep Agents.

---

# Expected Templates

- Sequential Workflow
- Conditional Workflow
- Event-Driven Workflow
- Autonomous Workflow
- Parallel Workflow
- Human-in-the-Loop Workflow
- Recovery Workflow

---

# Integration

Workflow templates integrate with:

- Workflow Engineering Engine
- Generation Orchestration Engine
- Harness Engineering Engine

---

# Engineering Standards

Generated workflow templates shall be deterministic, resumable, and traceable.
