# Code Review Agent

An AI agent that reviews code for quality, best practices, security vulnerabilities, and maintainability issues. Analyzes pull requests and produces structured review feedback.

## Quick Start

```bash
# Install
pip install -e .

# Set your API key
export AIM_API_KEY=your-key-here

# Run
python -c "from code_review_agent.agent import CodeReviewAgent; agent = CodeReviewAgent(); print(agent.run('Hello'))"
```

## Architecture

- Pattern: Planner-Executor
- LLM: Azure OpenAI
- Memory: Session-based
- Prompts: Externalized in `prompts/`

## Configuration

Edit `config.ini` with your Azure OpenAI endpoint:

```ini
[aim]
url = https://your-endpoint.openai.azure.com/
api_version = 2024-06-01
type = azure
models = aim-gpt-4o-mini-lab
```

Set your API key as an environment variable:

```bash
export AIM_API_KEY=your-key
```
